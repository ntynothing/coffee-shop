# Кофейня

Учебный проект: веб-приложение кофейни на HTML, CSS и JavaScript.

## Возможности

Пользователь: каталог с поиском и фильтром, корзина, оформление заказа с чеком, регистрация и вход, блог.

Администратор: управление товарами и блогом, просмотр заказов, доска стикеров с drag-and-drop, статистика с графиком и таблицей.

## Запуск

Откройте `index.html` в браузере или запустите через Live Server в VS Code.

Администратор: `admin@coffee.ru` / `admin123`

## Структура

- `index.html`, `catalog.html`, `cart.html`, `blog.html`, `login.html`, `admin.html`, `stats.html` — страницы
- `style.css` — оформление
- `app.js` — логика, данные хранятся в localStorage


## Обновление каталога

Каталог расширен до 24 позиций. У карточек товаров есть фотографии, поиск и фильтр по категориям сохранены. Фотографии загружаются по HTTPS из Unsplash, поэтому для их отображения требуется подключение к интернету.

### Запуск через Live Server
1. Распакуйте архив целиком в одну папку.
2. Откройте эту папку в Visual Studio Code.
3. Откройте `index.html` и нажмите **Go Live**.
4. Перейдите в раздел «Каталог».

Новые товары автоматически добавляются в существующий `localStorage`, поэтому старые данные браузера не мешают обновлению каталога.


## Изображения товаров
Все фотографии находятся в папке `images` и подключаются локально (интернет для них не нужен). Не перемещайте файлы отдельно от папки проекта.
